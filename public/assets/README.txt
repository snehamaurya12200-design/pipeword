haX.baby "Baby's First Website" Hackathon

OFFICIAL CHARACTER SPECIFICATION:
Pip is the official character provided by the hackathon organizers.
Pip is a cute baby with a smooth, round skull face, large soft eye sockets containing
warm glowing pinpricks of light, a tiny crooked smile, and a bedtime nightcap decorated
with stars and a small pink bow.

Profession: Junior Dream Engineer at the Midnight Nursery.
Official Tagline: "I build the dreams you fall asleep inside."

OFFICIAL ASSET FILE SLOTS:
- /assets/pip-waving-cloud.png  (Pip waving on a fluffy cloud)
- /assets/pip-portrait.png      (Pip portrait avatar)

The application automatically checks for these files at runtime. If the files are
present in this folder, they will be loaded into the desktop avatar widget and
applications. If not yet added, the built-in SVG vector rendering displays the exact
official character anatomy as specified, and the Asset Inspector window allows
previewing and verifying official files.
